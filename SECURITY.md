# 🔒 Security Policy

## 📌 Supported Versions

This project is actively maintained. Security updates will be applied to the latest version.

| Version | Supported |
|--------|-----------|
| Latest | ✅ Yes |
| Older Versions | ❌ No |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### 📬 How to Report

- Open a **private issue** (if possible), or  
- Contact the maintainer directly  

Please include:
- Description of the vulnerability  
- Steps to reproduce  
- Potential impact  
- Suggested fix (if available)

---

## 🔐 Responsible Disclosure

- Do **not publicly disclose** the vulnerability until it has been reviewed and fixed  
- Give maintainers reasonable time to respond and resolve the issue  

---

## ⚡ Response Timeline

We aim to:

- Acknowledge the issue within **48 hours**  
- Provide an initial assessment within **3–5 days**  
- Release a fix as soon as possible  

---

## 🛡 Security Best Practices

For contributors:

- Do not commit sensitive data (API keys, credentials)
- Use environment variables for secrets
- Validate inputs to avoid injection vulnerabilities
- Keep dependencies updated

---

## 📦 Dependency Management

- Regularly update packages
- Use tools like:
  - `pip-audit`
  - `safety`

---

## ⚠️ Scope

This project is focused on machine learning workflows and does not handle sensitive production data directly. However, security best practices should always be followed.

---

## 💡 Final Note

 Security is a shared responsibility. Responsible reporting helps improve the safety of this project.

🙏 Thank you for helping keep this project secure!
